## 作品管理

### 基本操作

- **新建作品**：点击标题栏作品名 → 新建作品，自动创建第一个空白章节
- **切换作品**：点击标题栏作品名，在下拉列表中选择其他作品
- **重命名**：点击标题栏作品名 → 重命名，或直接在标题栏编辑
- **删除作品**：点击标题栏作品名 → 删除当前作品（不可恢复）

### 备份与迁移

- **导出作品**：点击标题栏作品名 → 导出作品，保存为 `.inkark` 格式文件
  - 备份包含：所有章节、角色卡、世界观卡、AI 任务绑定
- **导入作品**：点击标题栏作品名 → 导入作品，选择 `.inkark` 文件
  - 每次导入自动生成新 ID，不会覆盖现有项目

## 章节编辑器

### 富文本编辑

- **基础格式**：加粗、斜体、下划线
- **撤销/重做**：支持多步撤销和重做
- **Tab 缩进**：按 Tab 键插入 4 个空格
- **自动保存**：编辑内容自动保存，无需手动操作

### 章节管理

- **章节标题**：在编辑器顶部直接编辑当前章节标题
- **章节大纲**：在标题下方的文本框中编写或查看章节大纲
  - 支持 AI 自动生成大纲
- **字数统计**：状态栏实时显示当前章节和全书字数

### AI 辅助大纲生成

- 点击工具栏的「生成大纲」按钮
- AI 将根据章节正文自动生成 100 字内的剧情大纲
- 生成后可手动编辑，确认后更新

### 变更审阅

- AI 修改章节内容时，会显示变更审阅界面
- 绿色高亮新增内容，红色高亮删除内容
- 支持接受或拒绝变更

## AI 写作助手

### 基本使用

- 点击右侧 AI 面板图标打开对话界面
- 支持两种模式：
  - **Write 模式**：AI 可以修改章节内容、创建角色/世界观等
  - **Chat 模式**：AI 只能查看项目信息，不能修改

### 写作功能

- **续写/扩写**：选中文本右键 → 扩写，或在 AI 面板描述需求
- **缩写**：选中文本右键 → 缩写，精简内容
- **润色**：选中文本右键 → 润色，优化选区表达
- **自由对话**：直接向 AI 描述你想要的内容，如「帮我写一段雨中追逐的场景」

### 多候选结果

- Write 模式下，AI 会生成 3 个不同版本供选择
- 可切换查看不同候选，选择最满意的版本

### DeepSeek 思考模式

- 支持显示 AI 的推理过程（需在 API 设置中开启）
- 可选择 `high` 或 `max` 两种推理强度
- 思考模式下 Temperature、Top-P 参数不生效

### 快捷命令

- AI 面板顶部有快捷命令按钮
- 右键快捷按钮可自定义：
  - 编辑命令名称和提示词
  - 设置是否自动发送
  - 设置是否生成多候选

### 对话历史

- 每个作品独立保存对话历史（最多 50 条）
- 切换作品时自动保存/加载对应历史
- 支持查看历史对话记录

### 右键菜单

在编辑器中选中文本后右键，可快速执行：

- **润色**：优化选中文本（编辑器左侧显示段落序号）
- **缩写**：精简选中文本
- **扩写**：丰富选中文本
- **发送到聊天框**：将选中文本发送给 AI

## AI 工具调用

AI 可以直接操作你的项目数据，无需手动切换界面。以下是 AI 能帮你做的事情：

### 章节操作

- 查看章节列表和大纲
- 读取指定章节的正文内容
- 批量创建新章节
- 修改章节标题
- 更新章节大纲
- 写入或修改章节正文

### 角色操作

- 查看所有角色卡
- 读取指定角色的详细设定
- 创建新角色或更新已有角色信息（支持批量操作）

### 世界观操作

- 查看所有世界观设定
- 读取指定世界观的详细信息
- 创建新设定或更新已有设定（支持批量操作）

### 大纲操作

- 查看全书大纲
- 创建或更新全书大纲（需使用 HTML 格式）
- 更新写作进度（需使用 HTML 格式）

**注意**：当 AI 要修改已有的角色或世界观时，会先请求你确认后才执行，不用担心误操作。

## 全书大纲

- 点击侧栏「大纲」按钮打开富文本编辑器
- **富文本编辑**：支持标题（H1/H2/H3）、加粗、斜体、下划线、分隔线等格式，所见即所得
- **AI 生成**：点击「重新生成」，通过 AI 辅助规划全书结构
  - 输入：书名、章节数量、故事创意
  - 输出：AI 生成的完整大纲（HTML 格式）
- **变更审阅**：AI 修改大纲时会显示 diff 视图，支持接受或拒绝变更

## 角色管理

### 基本操作

- 点击侧栏「角色」标签查看角色列表
- 支持按名称搜索角色
- 支持按标签筛选角色

### 角色卡信息

每个角色卡包含以下字段：

| 字段 | 说明 |
|------|------|
| 名称 | 角色名称（必填） |
| 别名 | 别名或称号 |
| 描述 | 角色简介 |
| 定位 | 角色在故事中的定位 |
| 性格 | 性格标签（顿号分隔） |
| 外貌 | 外貌描述 |
| 背景 | 背景故事 |
| 人际关系 | 与其他角色的关系 |
| 备注 | 其他信息 |
| 性别 | 角色性别 |
| 年龄 | 角色年龄 |
| 标签 | 用于分类筛选的标签 |

### 批量操作

- AI 支持批量创建或更新多个角色卡
- 可通过对话一次性处理多个角色设定

## 世界观管理

### 世界观卡信息

| 字段 | 说明 |
|------|------|

| 类型 | 地点/组织/规则/物品/其他 |

| 标签 | 用于分类筛选的标签 |
| 备注 | 其他信息 |

### 批量操作

- AI 支持批量创建或更新多个世界观设定

## 导出功能

点击编辑器工具栏的「导出」按钮，支持三种格式：TXT、Markdown、Word (DOCX)

导出设置：
- **书名**：默认使用作品标题
- **作者**：可选填
- **范围**：导出所有有内容的章节

## 写作写作风格

点击侧栏「写作风格」按钮打开风格面板：

### 内置风格

| 风格 | 特点 |
|------|------|
| 默认 | 标准写作风格 |
| 古风 | 半文半白，诗词意象 |
| 热血 | 节奏紧凑，战斗激烈 |
| 轻松 | 幽默调侃，节奏明快 |
| 悬疑 | 压抑神秘，伏笔埋设 |
| 细腻 | 心理丰富，情感深入 |

### 自定义风格

- 点击「添加自定义风格」创建个性化写作风格
- 设置风格名称和描述，AI 将按照描述进行写作
- 支持编辑和删除自定义风格

## 风格限制与敏感词

点击侧栏「限制管理」按钮打开限制面板：

### 风格限制

- 自定义写作限制
- AI 将在写作时遵守这些限制
- 示例：
  - 禁止使用特定句式
  - 避免使用成语

### 敏感词管理

- **内置敏感词**：预设的屏蔽词（不可删除）
- **自定义敏感词**：用户添加的屏蔽词
- 添加后 AI 将在写作时自动规避这些词语

## API 配置

点击标题栏 → 设置 → API 配置，管理 AI 服务：

### 支持的提供方

| 提供方 | 说明 |
|--------|------|
| InkArk | 官方免费 API，开箱即用（新用户免费体验一个月） |
| DeepSeek | DeepSeek 官方 API |
| OpenAI 兼容 | 任何兼容 OpenAI 接口的 API（如 OpenAI、硅基流动、零一万物、通义千问等） |

### 参数预设

每个 API 配置可设置参数预设：

| 参数 | 说明 |
|------|------|
| Temperature | 生成随机性（0-2，0 最确定，2 最随机） |
| Top-P | 核采样参数（0-1） |
| Max Tokens | 单次最大生成长度 |
| 思考模式 | 开启/关闭推理过程显示 |

### 多配置支持

- 可添加多个 API 配置
- 不同写作任务可绑定不同预设
- 支持测试 API 连接

## 数据存储

数据库位置按平台区分：

- **Windows**：便携式模式，数据库位于 `{安装目录}\data\inkark.db`，升级时由 NSIS 安装脚本自动备份恢复
- **macOS**：位于 `~/Library/Application Support/InkArk/inkark.db`（macOS 推荐的标准应用数据位置，不会被应用更新覆盖）
  - 自定义字体：`~/Library/Application Support/InkArk/fonts/`
  - 老版本曾放在 `InkArk.app/Contents/MacOS/data/`，升级到当前版本时会**自动迁移**到上述标准路径；原 `data/` 留作备份，可手动清理
- 建议定期使用「导出作品」备份为 `.inkark` 文件，多一份兜底

### 自动更新

- **Windows**：应用内自动检查 / 下载 / 安装
- **macOS**：暂不支持应用内自动更新（需 Apple 开发者签名与公证）；请前往官网下载新版本手动替换
